About Project

Voo-ong은 '지혜'의 상징인 부엉이와 영화 필름 릴을 결합한 이름입니다.
빅데이터 분산 처리와 머신러닝 기술을 활용하여 사용자 개인의 취향을 정밀하게 분석합니다.

🔍 개인화 추천

타인의 리뷰와 평점에 의존하지 않고, 오직 사용자의 개인 평가 데이터만을 분석하여 추천합니다.

💾 빅데이터 처리

Hadoop 생태계(HDFS, Hive, Sqoop)를 구축하여 2,800만 건 이상의 대용량 평점 데이터를 분산 처리합니다.

🤖 머신 러닝

TensorFlow와 Keras를 활용한 다중 라벨 분류 모델을 통해 사용자가 선호할 장르를 예측합니다.

Why & How

The Problem

  • 기존 시스템은 타인의 평점에 큰 영향을 받음
  • 유명하지 않은 영화는 추천받기 어려움 (Long-tail 문제)
  • 단순 평점 기반 추천의 낮은 정확도
  • "내가 진짜 좋아하는 장르가 뭐지?"에 대한 답을 찾기 어려움

The Solution

  • 타인 리뷰 배제: 순수 개인 평가 기반 시스템 개발
  • 데이터 수집: IMDb, MovieLens 데이터 및 네이버 영화 크롤링
  • 태그화: 영화 정보 태그화 및 사용자 평가 매핑
  • 피드백 루프: 추천 결과에 대한 재평가를 학습에 반영

  • VirtualBox

Big Data

  • Hadoop (HDFS)

AI & Data Science

  • Python
  • TensorFlow / Keras

Web & DB

  • MySQL (RDBMS)

  • Node.js (App Server)
  • HTML/CSS

Development Process

1. 환경 구축

Azure 클라우드 및 VirtualBox에 CentOS 7 환경 구성. SSH 보안 설정 및 네트워크 구성.

2. 빅데이터 플랫폼 구축

Hadoop 클러스터 구축 (Ambari, Cloudera Manager 활용). MySQL, Hive, Sqoop 연동을 통한 데이터 파이프라인 설계.

3. 데이터 수집 및 전처리

IMDb, MovieLens 데이터 다운로드 및 네이버 영화 크롤링. 데이터 정제, 장르 One-hot Encoding, 평점 MinMax Scaling 수행.

4. 머신 러닝 모델 개발

Multi-label Classification 모델 설계. SGD, Adam, Nadam 최적화 알고리즘 비교 분석 및 튜닝.

Project Result

부족한 리소스와 짧은 기간에도 불구하고 유의미한 성과를 달성했습니다.
